## Phase 1 — Scaffold

**Goal**: Repo structure, tooling, documentation skeletons, first push to GitHub.

**Shipped**:
- npm workspace at the repo root with `shared/` and `server/` workspaces (the `client/` workspace will be generated by Vite when frontend work starts, to avoid scaffolding it twice).
- Strict TypeScript base config consumed by both workspaces (`noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, etc.).
